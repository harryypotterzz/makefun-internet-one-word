`main.py` (Python 3 standard library only) writes a single word to `output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The word

**slop**

The whole internet in one word: a flood of low-effort, machine-made content — listicles, AI images, rage bait — poured over everything worth reading. It is funny because it is blunt, true because it describes the feed as it actually is, and short enough to land in one beat.
